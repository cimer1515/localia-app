# LOCALIA

**Business Setup & Compliance Assistant**

LOCALIA ayuda a emprendedores a preparar la apertura de su negocio mediante una guía de requisitos según actividad y ubicación, organización documental y un esquema visual inicial del local con señalética sugerida.

> Esta primera versión es un prototipo informativo. No emite permisos oficiales ni sustituye planos técnicos, inspecciones o validación de la autoridad competente.

## MVP
- Landing page del proyecto
- Selección de tipo de negocio y ciudad
- Lista orientativa de requisitos
- Esquema visual básico del establecimiento
- Señalética sugerida y checklist

## Ejecutar localmente
```bash
npm install
npm run dev
```

## Despliegue en Netlify
- Build command: `npm run build`
- Publish directory: `dist`

## Tecnologías
Vite + JavaScript + CSS. Prototipo inicial sin backend.

## Estado
Scaffold inicial para el hackathon MetaEarth HARBOR. Los requisitos deben verificarse con fuentes oficiales locales antes de presentarse como definitivos.
